# ระบบจองห้องประชุมทางไกลผ่านจอภาพ — ศาลจังหวัดอุดรธานี

เว็บสำหรับจองห้องประชุมทางไกล (Video Conference) พร้อมระบบหลังบ้าน
ใช้ **TailwindCSS + SweetAlert2** ฝั่งหน้าเว็บ, **Vercel Serverless Functions** ฝั่ง API และ **Neon (PostgreSQL)** เป็นฐานข้อมูล

## ความสามารถ

**หน้าเว็บสาธารณะ** (`/`)
- แบบฟอร์มจอง พร้อมตรวจสอบข้อมูล (IP, เวลา) และยืนยันก่อนบันทึก
- ตรวจเวลาทับซ้อนอัตโนมัติ — แจ้งเตือนและให้ยืนยันหากต้องการจองซ้อน
- ตารางการจอง (กำลังจะถึง / ที่ผ่านมา / ทั้งหมด) + ค้นหา
- ปฏิทิน (เดือน / สัปดาห์ / รายการ) แสดงปี พ.ศ.
- ไม่แสดงเบอร์โทรและ IP ต่อสาธารณะ (เห็นเฉพาะเจ้าหน้าที่)

**หลังบ้าน** (`/admin`)
- เข้าสู่ระบบด้วยคุกกี้ HttpOnly (หมดอายุ 8 ชม.) รหัสผ่านเข้ารหัสแบบ scrypt
- ครั้งแรกที่เปิด จะให้สร้างบัญชีผู้ดูแลระบบคนแรก
- ภาพรวม: สถิติวันนี้ / 7 วัน / เดือนนี้, ตารางวันนี้, รายการล่าสุด
- รายการจอง: เพิ่ม / แก้ไข / ลบ, เปลี่ยนสถานะ (ยืนยันแล้ว / รอตรวจสอบ / ยกเลิก), หมายเหตุภายใน, กรองตามวันที่/สถานะ
- พิมพ์รายงาน / บันทึก PDF (A4 แนวนอน) และส่งออก Excel (CSV)
- ดึงประวัติการจองจาก Google Sheet เดิมอัตโนมัติหลังสร้างผู้ดูแลคนแรก (และกดดึงซ้ำได้ที่ปุ่ม "ดึงประวัติจาก Google Sheet") — ข้ามรายการซ้ำ, แก้ปี พ.ศ./เวลา/เบอร์โทรที่ 0 หาย ให้อัตโนมัติ
- ผู้ใช้งาน: เพิ่ม / แก้ไข / ลบ / ปิดใช้งาน, สิทธิ์ "ผู้ดูแลระบบ" และ "เจ้าหน้าที่"
- ฝังปฏิทินในเว็บอื่น: ตั้งค่ามุมมอง/ขนาด/หัวข้อ ดูตัวอย่าง แล้วคัดลอกโค้ด `<iframe>` ได้ทันที
- เปลี่ยนรหัสผ่านของตนเอง

**ปฏิทินสำหรับฝัง** (`/embed`) — ใส่ใน `<iframe>` ได้จากทุกเว็บไซต์
ค่าเริ่มต้นแสดงเฉพาะปฏิทิน (เหมือนในหน้าจอง) — พารามิเตอร์: `view=month|week|list`, `header=1`, `footer=1`, `title=...`, `nav=0`, `details=0`, `compact=1`, `refresh=<นาที>`

## โครงสร้าง

```
api/            Vercel Functions (auth, bookings, users)
lib/            เชื่อม Neon, เข้ารหัสรหัสผ่าน/คุกกี้, helper
public/         หน้าเว็บ (index.html, admin.html, embed.html, assets/)
schema.sql      โครงสร้างตาราง (ระบบสร้างให้อัตโนมัติ ไม่ต้องรันเอง)
legacy/         ไฟล์ระบบเดิม (เก็บไว้อ้างอิง ไม่ถูก deploy)
```

## การติดตั้งบน Vercel + Neon

1. Push โปรเจกต์นี้ขึ้น GitHub
2. ที่ [vercel.com/new](https://vercel.com/new) เลือก Import repository นี้ → Framework Preset: **Other** → Deploy
3. ในโปรเจกต์ Vercel ไปที่ **Storage → Create Database → Neon** แล้วเชื่อมกับโปรเจกต์
   (Vercel จะตั้งค่า `DATABASE_URL` ให้อัตโนมัติ) — หรือสร้างฐานข้อมูลเองที่ [neon.tech](https://neon.tech) แล้วนำ connection string มาใส่ใน **Settings → Environment Variables** ชื่อ `DATABASE_URL`
4. (แนะนำ) เพิ่ม Environment Variable `AUTH_SECRET` เป็นข้อความสุ่มยาว ≥ 32 ตัวอักษร
5. กด **Redeploy** เพื่อให้ค่าใหม่มีผล
6. เปิด `https://<โดเมน>/admin` → สร้างบัญชีผู้ดูแลระบบคนแรก → ระบบจะดึงประวัติจาก Google Sheet เดิมเข้ามาให้ทันที

> ถ้า URL ของ Apps Script เดิมเปลี่ยน ให้ตั้ง Environment Variable `LEGACY_SCRIPT_URL`

ตารางในฐานข้อมูลจะถูกสร้างอัตโนมัติเมื่อเรียกใช้งานครั้งแรก

## รันบนเครื่อง

```bash
npm i -g vercel
npm install
cp .env.example .env.local   # ใส่ DATABASE_URL
vercel dev
```
